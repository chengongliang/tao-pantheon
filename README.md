# 道藏通鉴 · 道家源流与仙真图谱

> 探索中华道家思想渊源、历代重大事件编年、三清六御与历代仙真谱系，配有互动式人物关系图谱、历史时间轴与高清丹青图像志的中华道文化数字典藏馆。

---

## 项目简介

**「道藏通鉴」** 是一座以东方古籍与博物馆策展美学为灵感的单页 Web 数字典藏应用。全站围绕道家从先秦诸子哲学走向宗教体系化、宗派鼎立与世俗文化浸润的两千余年历程，以**五卷展陈结构**完整呈现道教历史脉络、神仙位业谱系与人物关系网络。

---

## 核心展卷与功能亮点

### 第一卷 · 渊源与流变（5 大核心篇章）
- 系统梳理从先秦黄老哲学、道家思想奠基、东汉天师道创立、魏晋南北朝神谱定型、唐宋金元全真与正一双轨并立，到明清宫观与民俗融汇的演进历程。

### 第二卷 · 历史重大事件时间轴（12 大编年里程碑）
- 覆盖 **先秦 → 秦汉 → 魏晋南北朝 → 隋唐 → 宋元 → 明清** 六大历史时期。
- 支持按朝代分期筛选、展开事件详述，并可直接点击关联仙真跳转查阅档案或在人物图谱中高亮定位。

### 第三卷 · 仙真丹青图鉴与神系总录（60 位核心仙真）
- **60 位仙真与历代宗师全传**：涵盖三清至圣、上古创世、六御二祖、五老星冥、上古先秦先哲、天师祖师、护法民俗神祇与民间八仙。
- **三维多模式排序**：
  - **按重要顺序（默认）**：按道教核心位格、历史奠基作用与文化影响力排序（`元始天尊 → 灵宝天尊 → 道德天尊 → 老子 → 玉皇大帝 → 盘古 → 伏羲与女娲 → 轩辕黄帝 → 张道陵 → 庄子……`）。
  - **按时间顺序**：依 `太初创世 → 上古三皇五帝 → 商周先秦 → 秦汉 → 魏晋南北朝 → 隋唐 → 五代两宋 → 金元 → 元明清` 历史断代排序，卡片同步显示时序编号与断代标签。
  - **按正统神阶**：依八阶正统神谱位业排布，便于与人物图谱对照查阅。
- **多维筛选与全文检索**：支持按神阶分类、关键词、道号、经典著作与断代检索。
- **道教神系考辨总录**：内嵌可展开学术专题面板，包含 **6 阶段神系演进史**、**六合六御方位图解**、**正统神系常见误区考辨**、**9 大重要神仙位业总表**，以及 **二十八星宿、北斗七星、南斗六星、全真七子、四大真人、五路财神、六十甲子太岁** 完整名录。

### 第四卷 · 互动式人物关系图谱（60 节点 · 90 条脉络）
- 基于可交互 SVG 画布构建的八阶神系全景关系网络，支持：
  - 按关系类型（化生、师承、统属、同门、典籍传承、结盟护法等）实时高亮筛选；
  - 点击任意节点聚焦其一阶关联脉络，右侧面板同步展示人物简介、关联列表与档案入口；
  - 缩放、平移与重置视图操作，并支持从时间轴或图鉴卡片一键定位节点。

### 第五卷 · 丹青图像志（64 幅定制高清配图）
- 收录 **64 幅独立无重复的东方水墨工笔风格丹青画作**，涵盖 60 位仙真人物造像及《道德经》简帛、楼观台、龙虎山天师府、武当山金顶等名山典籍藏品。
- 同步支持 **按重要顺序 / 按时间顺序 / 按正统神阶** 排序与题材分类筛选，点击任意藏品可开启高清灯箱模式沉浸赏析与上下翻页。

## 技术栈

- **前端框架**：React 19 + TypeScript
- **构建工具**：Vite 8
- **样式方案**：Tailwind CSS 4（`@tailwindcss/vite`）
- **图标与动效**：`lucide-react`、`motion`
- **测试工具**：Node.js 原生测试运行器（`node:test` + `tsx`）

## 快速开始

### 环境要求

- Node.js >= 20
- npm >= 10

### 安装依赖

```bash
npm install
```

### 启动本地开发服务器

```bash
npm run dev
```

默认运行在 `http://localhost:3000`。

### 类型检查与单元测试

```bash
# TypeScript 静态类型检查
npm run lint

# 运行数据完整性、筛选、排序与图谱逻辑单元测试
npx tsx --test src/utils/taoismLogic.test.ts
```

### 生产环境构建与预览

```bash
# 构建生产包（输出至 dist/）
npm run build

# 本地预览生产构建结果
npm run preview
```
